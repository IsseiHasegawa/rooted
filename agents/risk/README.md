# rooted-risk

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Scores the CDC STEADI "Stay Independent" fall-risk screening and lists room-by-room home hazards from the CDC "Check for Safety" checklist. Called by rooted-orchestrator with AssessRequest; answers AssessResult.

Messages are defined in `shared/models.py`.
