# rooted-funding

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Matches home-modification grants and insurance benefits (LACDA Senior Grant, NHS LA County, PICF HUD, Medicare Advantage B14c) with deterministic rules and cites each source. Called by rooted-orchestrator with FundingRequest; answers FundingResult.

Messages are defined in `shared/models.py`.
