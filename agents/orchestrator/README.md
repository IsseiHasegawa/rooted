# rooted-orchestrator

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Rooted helps families make an older parent's home safer so they can age in place. Chat with this agent to run a CDC STEADI fall-risk screening, see an "after" image of a safer bathroom, compare three contractor quotes, match grants and insurance benefits, split the cost with siblings, and pay a deposit.

## Example prompts

- My mom lives alone and I'm worried about her bathroom.
- Help me make my dad's home safer so he can stay there.

Messages are defined in `shared/models.py`.
